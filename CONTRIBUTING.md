# Contributing to blackjack-card-game

Thank you for your interest in contributing to this project! Contributions, bug reports, suggestions, and improvements are welcome.

## How to Contribute
### 1. Fork the Repository

Fork this repository to your own GitHub account and clone your fork locally.

git clone https://github.com/NAU-OSS/blackjack-card-game.git  
cd blackjack-card-game
### 2. Create a Branch

Create a new branch for your changes.

git checkout -b feature/your-feature

### 3. Make Your Changes

Make your changes while keeping the following guidelines in mind:

- Keep the code readable and organized.
- Follow the existing coding style.
- Avoid unnecessary changes to unrelated parts of the project.
- Add comments when they help explain complicated logic.
- Test your changes before submitting them.
### 4. Test the Game

Before submitting a contribution, make sure the game builds and runs correctly.  

Test any new functionality and make sure existing functionality still works.

### 5. Commit Your Changes

Use a clear and descriptive commit message.

git add .
git commit -m "Add support for splitting pairs"
### 6. Push Your Branch

Push your branch to your GitHub fork.

git push origin feature/your-feature
### 7. Open a Pull Request

Open a pull request from your branch to the main repository.

In your pull request, briefly describe:

- What you changed
- Why you made the change
- How you tested it
- Any issues or limitations that should be considered
## Reporting Bugs

If you find a bug, please open an issue and include:

- A description of the problem
- Steps to reproduce the problem
- What you expected to happen
- What actually happened
- Your operating system
- Any relevant error messages
## Feature Requests

Feature requests are welcome. When suggesting a feature, explain:

- What the feature would do
- Why it would be useful
- How it could improve the game

## Code of Conduct

Please be respectful and constructive when interacting with other contributors. Contributions should focus on improving the project and helping create a welcoming environment for everyone.
